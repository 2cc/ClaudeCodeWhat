- Сторонние программы, которые помогают работать с Claude Code и другими AI-агентами.
- herdr
	- Терминальный мультиплексор для AI-агентов: как tmux, но знает, в какой панели агент и что он сейчас делает.
		- Один бинарник на Rust, работает внутри обычного терминала (ghostty, kitty, alacritty, wezterm, даже внутри tmux).
		- Сайт и документация: https://herdr.dev, исходники: https://github.com/ogulcancelik/herdr
	- Зачем: несколько агентов параллельно без кучи вкладок и без проверки каждой — видно, кто ждёт ответа.
	- Установка: `curl -fsSL https://herdr.dev/install.sh | sh`. Обновление — `herdr update`.
	- Устройство
		- Workspace — проект или задача. Обычно один на репозиторий.
		- Tab — вкладка внутри workspace: агенты, логи, сервер.
		- Pane — настоящий терминал, панели делятся вправо и вниз.
		- Session — фоновый сервер, который держит всё это. Обычно хватает одной, по умолчанию.
	- Состояние агентов
		- У каждой панели с агентом метка: `working` — работает, `blocked` — ждёт подтверждения или ответа, `done` — закончил, `idle` — свободен.
		- В боковой панели состояния сведены по всем workspace сразу.
		- Агент остановился и ждёт — приходит уведомление.
		- Понимает Claude Code, Codex, Cursor, OpenCode, Grok и другие.
	- Интеграция с Claude Code
		- `herdr integration install claude` — ставит [хук](hooks.md) `~/.claude/hooks/herdr-agent-state.sh`.
		- Без неё herdr угадывает состояние по выводу терминала, с ней — Claude сам сообщает о нём. Плюс восстановление сессии агента.
		- Проверить, что стоит: `herdr integration status`.
	- Работа
		- `cd` в проект и `herdr` — запускает или подключается к уже запущенной сессии.
		- В панели запустить `claude`.
		- Мышь работает полностью: клик по панелям и вкладкам, перетаскивание границ, правый клик — меню.
		- Клавиши как в tmux: префикс `Ctrl+B`, отпустить, затем клавиша.
			- `prefix+v` — разделить вправо, `prefix+-` — вниз.
			- `prefix+h/j/k/l` — перейти в соседнюю панель, `prefix+z` — развернуть панель на весь экран.
			- `prefix+c` — новая вкладка, `prefix+Shift+N` — новый workspace.
			- `prefix+q` — отключиться, `prefix+?` — все текущие клавиши.
	- Фон и восстановление
		- Закрыл терминал или отключился — терминалы и агенты продолжают работать в фоновом сервере. Вернуться — снова `herdr`.
		- После перезагрузки машины восстанавливает раскладку.
		- `herdr --remote <ssh-хост>` — подключиться к herdr на удалённой машине.
	- Worktrees
		- `prefix+Shift+G` или `herdr worktree create` — новый git [worktree](worktrees.md) сразу отдельным workspace.
		- Удобно для параллельных агентов в одном репозитории: у каждого свои файлы и ветка.
	- Агенты управляют herdr сами
		- Через CLI `herdr` агент может открыть панель, запустить в ней другого агента, прочитать вывод и дождаться, пока тот закончит.
		- `herdr --skill` печатает готовый [skill](skills.md) с инструкцией для агента.
		- Работает только внутри панели herdr (`HERDR_ENV=1`).
	- Настройки — `~/.config/herdr/config.toml`. Все параметры с комментариями: `herdr --default-config`.
- Советы
	- herdr нужен, когда агентов больше одного. Для одной сессии Claude Code хватает обычного терминала.
	- Сразу ставить интеграцию `herdr integration install claude`: без неё статусы угадываются и бывают неточными.
	- Параллельных агентов в одном репозитории запускать в отдельных worktree, иначе они правят одни и те же файлы.
	- Долгие задачи запускать в herdr: можно закрыть терминал или потерять SSH, и работа не прервётся.
