- Сторонние программы, которые помогают работать с Claude Code и другими AI-агентами, и альтернативные агенты.
- herdr
	- Терминальный мультиплексор для AI-агентов: как tmux, но знает, в какой панели агент и что он сейчас делает.
		- Один бинарник на Rust, работает внутри обычного терминала (ghostty, kitty, alacritty, wezterm, даже внутри tmux).
		- Сайт и документация: https://herdr.dev, исходники: https://github.com/ogulcancelik/herdr
	- Зачем: несколько агентов параллельно без кучи вкладок и без проверки каждой — видно, кто ждёт ответа.
	- Установка: `curl -fsSL https://herdr.dev/install.sh | sh`. Обновление — `herdr update`.
	- Устройство
		- Workspace — проект или задача. Обычно один на репозиторий.
		- Tab — вкладка внутри workspace: агенты, логи, сервер.
		- Pane — настоящий терминал, панели делятся вправо и вниз.
		- Session — фоновый сервер, который держит всё это. Обычно хватает одной, по умолчанию.
	- Состояние агентов
		- У каждой панели с агентом метка: `working` — работает, `blocked` — ждёт подтверждения или ответа, `done` — закончил, `idle` — свободен.
		- В боковой панели состояния сведены по всем workspace сразу.
		- Агент остановился и ждёт — приходит уведомление.
		- Понимает Claude Code, Codex, Cursor, OpenCode, Grok и другие.
	- Интеграция с Claude Code
		- `herdr integration install claude` — ставит [хук](hooks.md) `~/.claude/hooks/herdr-agent-state.sh`.
		- Без неё herdr угадывает состояние по выводу терминала, с ней — Claude сам сообщает о нём. Плюс восстановление сессии агента.
		- Проверить, что стоит: `herdr integration status`.
	- Работа
		- `cd` в проект и `herdr` — запускает или подключается к уже запущенной сессии.
		- В панели запустить `claude`.
		- Мышь работает полностью: клик по панелям и вкладкам, перетаскивание границ, правый клик — меню.
		- Клавиши как в tmux: префикс `Ctrl+B`, отпустить, затем клавиша.
			- `prefix+v` — разделить вправо, `prefix+-` — вниз.
			- `prefix+h/j/k/l` — перейти в соседнюю панель, `prefix+z` — развернуть панель на весь экран.
			- `prefix+c` — новая вкладка, `prefix+Shift+N` — новый workspace.
			- `prefix+q` — отключиться, `prefix+?` — все текущие клавиши.
	- Фон и восстановление
		- Закрыл терминал или отключился — терминалы и агенты продолжают работать в фоновом сервере. Вернуться — снова `herdr`.
		- После перезагрузки машины восстанавливает раскладку.
		- `herdr --remote <ssh-хост>` — подключиться к herdr на удалённой машине.
	- Worktrees
		- `prefix+Shift+G` или `herdr worktree create` — новый git [worktree](worktrees.md) сразу отдельным workspace.
		- Удобно для параллельных агентов в одном репозитории: у каждого свои файлы и ветка.
	- Агенты управляют herdr сами
		- Через CLI `herdr` агент может открыть панель, запустить в ней другого агента, прочитать вывод и дождаться, пока тот закончит.
		- `herdr --skill` печатает готовый [skill](skills.md) с инструкцией для агента.
		- Работает только внутри панели herdr (`HERDR_ENV=1`).
	- Настройки — `~/.config/herdr/config.toml`. Все параметры с комментариями: `herdr --default-config`.
- CodeGraph
	- Индекс кода проекта для агентов: где что определено и как связано. Claude спрашивает его вместо `grep` и чтения файлов.
	- Индекс — локальная SQLite-база в `.codegraph/`. Строится за пару секунд и не тратит токены модели.
		- Пока сервер работает, сам обновляет индекс по изменённым файлам.
	- Установка: CLI, затем `codegraph init` в проекте.
		- Подключает [MCP](MCP.md)-сервер с одним инструментом.
		- Дописывает в `CLAUDE.md` и `AGENTS.md`, что к нему надо обращаться раньше `grep`.
	- Тест The Gray Cat (одна фича, по одному прогону): токенов на 35% меньше (6,55 → 4,23 млн), навигационных вызовов при планировании 17 вместо 28.
- Graphify
	- Тоже граф проекта. Код разбирает локально, а документы и картинки — через LLM: индексация занимает минуты, стоит денег, обновлять её надо вручную.
	- С Claude Code интегрируется отдельной командой. Без неё Claude графом не пользуется и ищет как обычно.
	- В том же тесте токенов на 18% меньше, но при планировании граф почти не помог: Claude сам так сказал и перешёл на обычный поиск.
- Serena MCP и подобные оптимизаторы
	- Кирилл Мокевнин: по отзывам на Reddit токенов с ними уходит больше, а не меньше; такие оптимизации и так попадут в сами агенты. Замеров не привёл.
	- LSP не заменит grep: не видит переводы, серверные шаблоны, динамическую загрузку. Поэтому агенты ищут через grep и glob.
- OpenCode
	- Открытый терминальный агент для кода, аналог Claude Code и Codex CLI. Работает с любыми моделями: Codex по подписке ChatGPT, ключи API, бесплатные и локальные.
	- Claude — только по ключу API: подписку Pro/Max Anthropic в сторонние агенты не пускает.
	- Установка: `brew`, `curl`, `npm` или `bun`.
	- Кроме TUI — десктоп-приложение (бета, есть под Linux), веб-интерфейс и расширение для VS Code и Cursor.
	- Бесплатные модели есть из коробки. Платные у самого OpenCode: Zen — оплата за использование, Go — подписка $10.
	- Дешёвые и бесплатные провайдеры — подключаются через `/connect`.
		- Cerebras — бесплатный тариф, 1 млн токенов в день. Ключ: cerebras.ai → API Keys.
		- OpenRouter — бесплатные модели: без пополнения 50 запросов в день, после покупки кредитов на $10 — 1000. NullsCode называет $5.
		- GLM coding plan (Zhipu, GLM 4.7) — NullsCode: от $3 в месяц и работает хорошо. Довод — один лендинг в демо.
		- Подписка Google Antigravity — неофициальный плагин `opencode-antigravity-auth`, вход `opencode auth login` → Google OAuth. Даёт Gemini 3 Flash и другие модели Google.
	- Аналоги Claude Code
		- `Tab` — режимы Build и Plan, см. [режимы](режимы.md).
		- `Ctrl+P` — палитра команд, те же команды и через `/`.
		- `/diff` с источником last turn — правки только последнего хода, см. [/diff](!diff.md).
		- Fork conversation — новая сессия с контекстом до выбранного сообщения, как `/branch` в [/resume](!resume.md).
	- Что берёт из Claude Code
		- [Skills](skills.md) из `~/.claude/skills/` видит сразу, формат тот же.
		- [MCP](MCP.md)-серверы, настроенные для Claude Code, подключает сам.
		- Инструкции — из `AGENTS.md`, см. [AGENTS.md](_AGENTS.md.md).
	- Свой провайдер или прокси — секция `provider` в `opencode.json`: пакет `@ai-sdk/anthropic` для Claude-совместимого API, base URL, ключ, список моделей.
		- Base URL — с `/v1` на конце, без него запросы не проходят.
	- Локальные модели — через Ollama или LM Studio. Ollama сама предлагает прописать модель в конфиг OpenCode.
		- Антон Ларичев: Qwen 3.5 9B (~6 ГБ RAM) на старом MacBook так и не ответила на «привет». Нужны видеокарта и 32–64 ГБ RAM, и даже так до GPT 5.5 и Opus далеко. Это вывод из одной попытки.
- Советы
	- herdr нужен, когда агентов больше одного. Для одной сессии Claude Code хватает обычного терминала.
	- Сразу ставить интеграцию `herdr integration install claude`: без неё статусы угадываются и бывают неточными.
	- Параллельных агентов в одном репозитории запускать в отдельных worktree, иначе они правят одни и те же файлы.
	- Долгие задачи запускать в herdr: можно закрыть терминал или потерять SSH, и работа не прервётся.
	- Граф кода пробовать на большом проекте, где Claude много ищет. Начинать с CodeGraph: индекс бесплатный и обновляется сам.
	- Поставил такой инструмент — проверить по вызовам в плане, что Claude правда им пользуется, а не ищет `grep`.
	- OpenCode держать запасным агентом на случай проблем с подпиской Claude: skills и MCP переедут сами.
