- `@` для упоминания конкретных файлов.
- Содержимое файла целиком передаётся в запросе.
- Можно использовать внутри [_CLAUDE.md](_CLAUDE.md.md)
	- В этом случае содержимое файла тоже целиком будет передаваться в запросе.
- Советы
	- Знаешь, где дело, — указывать файл через `@`: Claude не тратит время и лимит на поиск.
	- Не знаешь — не угадывать, описать словами, Claude найдёт сам.
	- Большой файл через `@` целиком ляжет в контекст. Если нужна одна функция — лучше назвать путь и функцию.
	- В `CLAUDE.md` через `@` подключать только то, что нужно всегда. Остальное — просто путь: «подробности в `docs/api.md`», Claude прочтёт, когда понадобится.
