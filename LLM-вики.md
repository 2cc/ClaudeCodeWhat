- Личная база знаний, которую ведёт LLM: сырые источники лежат в папке, Claude Code раскладывает их по связанным Markdown-заметкам. Идея Андрея Карпати, см. [агентную инженерию](агентная%20инженерия.md).
	- Без векторных БД и эмбеддингов: только Markdown, индексы и ссылки.
	- Obsidian — только просмотрщик заметок и графа, без него тоже работает.
- Устройство
	- `raw/` — исходники как есть.
	- `wiki/` — что LLM сделала из сырья.
		- Страницы: один источник — 5–25 связанных страниц (люди, понятия, организации, анализ).
		- `index.md` — оглавление по разделам.
		- `log.md` — журнал операций, запись на каждый разобранный источник.
	- `CLAUDE.md` — схема: как устроена вики, как искать, как обновлять.
	- Плоская или с подпапками — зависит от назначения.
- Запуск
	- Готового репозитория нет: Карпати выложил идею gist'ом. Его текст вставить в Claude Code и попросить сделать вики под свою задачу, схему записать в `CLAUDE.md`.
	- Статьи из браузера — расширением Obsidian Web Clipper. В его настройках папку `Clippings` заменить на `raw`.
	- Дальше — «положил в raw, разбери». Claude уточняет, что важно и насколько подробно.
		- Nate Herk: большая статья — ~10 минут и 23 страницы, 36 транскриптов YouTube — ~14 минут.
- Подключение к другим агентам
	- В `CLAUDE.md` агента — путь к вики и порядок чтения: `hot.md` → `index.md` → индекс раздела → поиск.
	- Там же — «не читай вики без необходимости» и список задач, где она не нужна.
	- `hot.md` — ~500 слов о самом свежем, что недавно обсуждали. Нужен ассистенту, справочной базе — нет.
	- Nate Herk: перевёл своего ассистента с контекстных файлов на вики — токенов стало меньше. Цифр не привёл.
- Линтинг
	- Регулярно просить LLM проверить вики: противоречия между страницами, пробелы (дополнить веб-поиском), неочевидные связи, темы для новых страниц.
- Вики или RAG
	- Вики: поиск по индексам и ссылкам, только Markdown, платишь только токенами, поддержка — линтинг.
	- RAG: поиск похожих кусков по эмбеддингам, нужны векторная БД и нарезка, постоянные расходы, переиндексация при изменениях.
	- Предел вики — масштаб: сотни страниц с хорошими индексами — нормально, миллионы документов — нужен RAG или граф знаний.
		- У Карпати ~100 статей: LLM находит нужное сама, RAG не понадобился.
- Советы
	- Назначение вики объяснить Claude до первого источника: от него зависят структура и подробность разбора.
	- Подключая вики к агенту, давать путь и порядок чтения, а не `@`: иначе она целиком ляжет в каждый запрос, см. [file mention](file%20mention.md).
	- Линтинг запускать по расписанию: противоречия копятся незаметно.
