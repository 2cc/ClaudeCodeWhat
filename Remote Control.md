- Remote Control — управлять локальной сессией Claude Code с телефона или из браузера.
- Код и файлы остаются на компьютере, по защищённому соединению передаётся только управление.
- Запуск: `claude --remote-control [имя]`.
- Советы
	- Длинную задачу начать за компьютером и допиливать с телефона из другой комнаты или в дороге.
