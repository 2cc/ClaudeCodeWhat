- Плагин — готовый набор: [skills](skills.md), [субагенты](subagents.md), [hooks](hooks.md), [MCP](MCP.md)-серверы. Ставится одной командой.
- Плагины берут из маркетплейсов — каталогов плагинов. Официальный от Anthropic, `claude-plugins-official`, подключён сразу.
- Как поставить
	- `/plugin` — открыть панель, вкладка Discover: поиск по каталогу.
	- `/plugin install commit-commands@claude-plugins-official` — сразу открыть нужный плагин.
	- Перед установкой панель показывает, что плагин добавит, и для официальных — сколько токенов съест.
	- Выбрать, для кого ставить:
		- для себя во всех проектах — пишется в `~/.claude/settings.json`;
		- для всех в этом репозитории — в `.claude/settings.json`, его коммитят;
		- для себя только в этом репозитории — в `.claude/settings.local.json`.
		- Подробнее про эти файлы: [settings.json](_settings.json.md).
	- Если просит — `/reload-plugins`, чтобы плагин заработал в текущей сессии.
	- Skills плагина вызываются с приставкой: `/commit-commands:commit`.
- Чужой маркетплейс
	- `/plugin marketplace add owner/repo` — добавить каталог из GitHub.
	- Потом ставить как обычно: `/plugin install имя@маркетплейс`.
- Управлять
	- `/plugin`, вкладка Installed: `Space` — включить или выключить, `Enter` — подробности, обновить, удалить.
	- Там же раздел Not used recently — плагины, которыми давно не пользовался, но они всё ещё занимают контекст.
	- Из терминала: `claude plugin list`, `claude plugin disable имя@маркетплейс`, `claude plugin uninstall …`.
	- Официальные плагины обновляются сами, остальные — по кнопке Update now.
- Осторожно
	- Плагин может запускать хуки и MCP-серверы, то есть любой код на машине. Из незнакомых маркетплейсов ставить, только прочитав, что внутри.
	- Каждый включённый плагин добавляет описания своих skills в каждый запрос. Ненужные — выключать.
- Советы
	- Ставить по одному и смотреть, пользуешься ли. Не пользуешься — выключить.
	- Перед установкой смотреть, сколько токенов съест.
	- Плагины для команды ставить в проектную область: у новичка всё появится сразу после клонирования.
