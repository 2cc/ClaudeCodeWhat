- Claude Code работает прямо на GitHub: пишешь `@claude` в issue или PR — он отвечает, правит код, пушит коммиты, открывает PR.
- Под капотом — GitHub Action `anthropics/claude-code-action`, работает на раннерах GitHub Actions.
- Локальная работа с git — в [git](git.md).
- Подключить
	- Быстро: в репозитории запустить `claude` и выполнить `/install-github-app`.
		- Ставит Claude GitHub App, кладёт ключ в секреты репозитория, готовит PR с workflow-файлом. Остаётся смержить.
		- Нужны права админа в репозитории и установленный `gh` (`gh auth login`).
		- Только github.com. Для GitLab — отдельная инструкция про GitLab CI/CD.
	- Вручную:
		- Поставить приложение: github.com/apps/claude.
		- Добавить секрет: `ANTHROPIC_API_KEY` (ключ API) или `CLAUDE_CODE_OAUTH_TOKEN` (подписка Pro/Max, токен выдаёт `claude setup-token`).
		- Скопировать `examples/claude.yml` из репозитория action в `.github/workflows/`.
- Как пользоваться
	- Комментарий в issue или PR: `@claude поправь TypeError в компоненте дашборда`.
	- Claude отвечает комментарием и обновляет его по ходу работы.
	- Звать может только тот, у кого есть права на запись в репозиторий. Боты не могут, чтобы не зациклиться.
	- Если в workflow задан `prompt`, Claude работает без упоминания — на любое событие GitHub: открыли PR, расписание по cron.
		- В `prompt` можно вызвать [skill](skills.md): `/имя-скилла`.
		- Результат по умолчанию — в логе запуска, а не в комментариях.
- Ревью PR
	- При `/install-github-app` можно выбрать workflow для ревью — Claude комментирует каждый PR.
	- Для Team и Enterprise есть готовое ревью без workflow-файлов — см. [code review](code%20review.md).
- Настройка
	- `CLAUDE.md` в корне репозитория Claude читает и здесь — стиль кода, правила, см. [_CLAUDE.md](_CLAUDE.md.md).
	- `claude_args` в workflow — любые флаги Claude Code: `--max-turns 5`, `--model`, `--allowedTools`.
	- `trigger_phrase` — другое слово вместо `@claude`.
- Сколько стоит
	- Минуты GitHub Actions.
	- Токены: с ключом API — по тарифу API, с `CLAUDE_CODE_OAUTH_TOKEN` — из лимитов подписки, см. [токены и лимиты](токены%20и%20лимиты.md).
	- Экономить: конкретные запросы, короткий `CLAUDE.md`, `--max-turns`, таймаут на job.
- Осторожно
	- Ключи и токены — только в секретах GitHub, не в коде.
	- У Claude GitHub App широкий набор прав (код, issues, PR, workflows), выбрать часть нельзя.
	- Если не отвечает: установлено ли приложение, включены ли Actions, есть ли секрет, написано ли именно `@claude`.
- Советы
	- Начинать с небольших задач в issue и ревьюить PR от Claude как от нового разработчика.
	- Писать в `@claude` так же конкретно, как в терминале, см. [постановка задач](постановка%20задач.md).
	- Защитить основную ветку (branch protection): изменения от Claude попадают в неё только через PR и ревью.
	- Правила проекта держать в одном `CLAUDE.md` — он работает и локально, и в Actions.
