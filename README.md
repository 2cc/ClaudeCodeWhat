- Заметки о том, как работать с Claude Code.
- Читать можно прямо на GitHub или открыть папку как vault в Obsidian: там работают обратные ссылки, граф и сворачивание веток.
- Заметки про slash-команды называются с `!`: `/clear` лежит в `!clear.md`.
	- `/` в имени файла нельзя: и Obsidian, и файловая система считают его разделителем папок.
	- В ссылках виден сам `/clear`, `!` остаётся только в имени файла.
