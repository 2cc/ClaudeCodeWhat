- Уровень того, насколько сильно клод должен размышлять в текущей сессии
- Какой уровень лучше всего использовать
	- По гайду Anthropic к Opus 5.5 — начинать с `medium`: он стоит по умолчанию, по их тестам лучший баланс качества и скорости.
	- Повышать, только если не хватает качества: высокие уровни на простых задачах перемудряют и думают слишком долго.
- Смена уровня посреди беседы
	- Раньше сбрасывала кэш: вся беседа обрабатывалась заново и тратила лимит.
	- С Opus 5.5, по словам Anthropic, кэш сохраняется. Функция тестовая — проверить по `prompt_cache` в [статусной строке](статусная%20строка.md).
- Советы
	- По умолчанию не трогать, менять под задачу.
	- Рутина — переименования, мелкие правки, вопросы по коду — понизить: быстрее и дешевле.
	- Claude ошибается в логике, отладке, алгоритме — сначала поднять effort, потом уже менять [модель](!model.md).
	- Трудный только один запрос — [ultrathink](ultrathink.md) в нём, а не высокий уровень на всю сессию.
	- Высокий effort не спасает расплывчатую задачу: сначала [сформулировать](постановка%20задач.md), потом думать дольше.
	- Подобрать свой уровень: попросить Claude прогнать одну реальную задачу из работы на всех уровнях и сравнить результаты. Лучший поставить по умолчанию.
			- Сравнивать вслепую: сначала оценить результаты, потом смотреть, где какой уровень или модель.
