- `/config` — меню личных настроек Claude Code, чтобы не править файлы руками.
- Открывается на вкладке Config. `/status` открывает то же окно на вкладке Status.
- В меню короткий список: тема, режим редактора (vim), подробный вывод (verbose), подсказки и т. п. Это не все ключи [settings.json](_settings.json.md).
- Изменения применяются сразу, `Esc` закрывает меню с сохранением.
- `/` в меню — поиск по настройкам.
- Одну настройку без меню: `/config verbose=true`.
- Куда сохраняет
	- Большинство — в `~/.claude/settings.json`, то есть для всех проектов.
	- Некоторые (например, Show tips) — в `.claude/settings.local.json` текущего проекта.
	- Часть — в `~/.claude.json`: служебный файл Claude Code, руками его править не нужно.
	- Вкладка Config — не просмотр `settings.json`. Если тот же ключ задан в проектном файле, он перебьёт выбранное в меню, см. «Кто главнее» в [settings.json](_settings.json.md).
- Что настраивается не здесь
	- Модель — [/model](!model.md).
	- Уровень размышления — [/effort](!effort.md).
	- Разрешения — `/permissions`.
	- Статусная строка — [/statusline](статусная%20строка.md).
	- Клавиши — [/keybindings](горячие%20клавиши.md).
	- В VS Code и desktop-приложении `/config` нет: там свои настройки или правка файла.
- Советы
	- Через `/config` — личные вкусы: тема, vim, подсказки. Общие для команды настройки — руками в `.claude/settings.json`, его коммитят.
	- Выбранное в меню не действует — проверить, не перебивает ли проектный файл: `/status`, строка `Setting sources`.
	- Искать настройку через `/` в меню, а не листать.
