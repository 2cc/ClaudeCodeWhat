- Вернуться к прошлой беседе: вся история, вызовы инструментов и их результаты.
- Беседы сохраняются сами по ходу работы, в том числе после [/clear](!clear.md).
- Как вернуться
	- `claude --continue` (`-c`) — последняя беседа в текущей папке.
	- `claude --resume` (`-r`) — открыть список бесед.
	- `claude --resume <имя>` — сразу нужную, если давал ей имя.
	- `/resume` — переключиться на другую беседу, не выходя из Claude Code.
	- `claude --from-pr 1234` — беседы, в которых создан PR 1234, см. [git](git.md).
- Список бесед
	- `↑` `↓` — выбрать, `Enter` — открыть.
	- `Space` — посмотреть, что в беседе, не открывая.
	- Начать печатать или `/` — поиск. Можно вставить ссылку на PR.
	- `Ctrl+R` — переименовать.
	- `Ctrl+B` — только беседы с текущей git-ветки.
	- `Ctrl+A` — беседы из всех проектов, а не только из текущего.
	- `Ctrl+W` — из всех [worktrees](worktrees.md) репозитория.
	- `Esc` — выйти.
- Имена
	- Без имени беседу назовут по первому запросу. Найти по такому названию можно, но своё имя надёжнее.
	- `claude -n auth-refactor` — дать имя при запуске.
	- `/rename auth-refactor` — по ходу беседы.
	- Потом: `claude --resume auth-refactor`.
- Ответвиться
	- `/branch [имя]` — копия беседы, дальше работаю в копии. Оригинал остаётся как был.
	- `claude --continue --fork-session` — то же из командной строки.
	- Не путать с [/rewind](!rewind.md): тот откатывает назад внутри одной беседы.
- Что восстанавливается
	- История беседы, [модель](!model.md), [режим](режимы.md) при запуске через `--continue` или `--resume <имя>`.
	- Не восстанавливаются флаги запуска вроде `--add-dir` и `--mcp-config` — передать заново. Настройки из [settings.json](_settings.json.md) перечитываются сами.
	- Долгая беседа (больше 100k токенов), к которой не возвращался больше часа: Claude Code спросит, открыть её целиком или сжатой, как после [/compact](!compact.md). Сжатая дешевле на каждом следующем запросе, см. [токены и лимиты](токены%20и%20лимиты.md).
- Где лежат
	- `~/.claude/projects/<проект>/<id сессии>.jsonl`.
	- Хранятся 30 дней, срок меняется ключом `cleanupPeriodDays` в settings.json.
	- `/export` — сохранить беседу в читаемый текстовый файл или скопировать.
	- Если открыть одну беседу в двух терминалах без `--fork-session`, сообщения перемешаются.
- Советы
	- Беседам, к которым вернёшься, давать имена — `/rename`.
	- Новая задача — новая беседа, а не `/resume` старой: чужой контекст мешает.
	- Вернулся к долгой беседе через несколько часов и подробности не нужны — открыть сжатой, это дешевле.
	- Попробовать другой путь, не ломая беседу, — `/branch`.
	- Важные итоги хранить в файлах, а не в беседе: беседы удаляются через 30 дней.
