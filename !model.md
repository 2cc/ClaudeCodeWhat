- `/model` — выбрать модель, на которой работает Claude.
- Без аргумента открывает список, `/model opus` переключает сразу.
- `Alt+P` открывает тот же список, не стирая набранный запрос.
- Какие модели есть
	- `opus` — сильнее в рассуждениях: сложные задачи, планирование. Стоит по умолчанию на большинстве тарифов.
	- `sonnet` — повседневная работа с кодом, быстрее и экономнее.
	- `haiku` — самая быстрая и дешёвая: простые вопросы, фоновые задачи.
	- `fable` — самые длинные и трудные задачи, где неясно, с чего начать. Доступна не везде.
	- `opusplan` — Opus в режиме [plan](режимы.md#^plan), Sonnet при выполнении плана.
	- `default` — сбросить выбор и вернуться к модели по умолчанию.
	- Названия ведут на последнюю версию: `opus` сейчас — Opus 5.5.
	- `[1m]` в конце (`opus[1m]`) — контекстное окно на миллион токенов. У новых моделей (Sonnet 5+, Opus 4.7+, Fable) такое окно и так.
	- Модели не Anthropic — через OpenRouter или Ollama Cloud. Claude Code заточен под Opus и Sonnet, с другими работает хуже.
- Сохраняется ли выбор
	- `Enter` в списке — переключить и сделать моделью по умолчанию для новых сессий.
	- `s` в списке — переключить только на эту сессию.
	- `/model opus` — как `Enter`, сохраняет.
	- `claude --model opus` — только на эту сессию.
	- Руками: ключ `model` в [settings.json](_settings.json.md).
	- Смена модели действует и на субагентов, которые берут модель сессии.
- Модель и effort
	- В том же списке стрелками влево-вправо меняется [/effort](!effort.md).
	- Модель — насколько Claude умный, [/effort](!effort.md) — сколько та же модель думает над ответом.
- Advisor — основная модель по ходу задачи советуется с более сильной: перед выбором подхода, на повторяющейся ошибке, перед «готово».
	- Advisor видит всю беседу с вызовами инструментов. Когда его звать, решает Claude.
	- `/advisor opus` — включить, `/advisor off` — выключить. На одну сессию — `claude --advisor opus`, в настройках — `advisorModel`.
	- Advisor не может быть слабее основной модели: для Sonnet 5.5 подходят Opus 5+ или Fable.
	- Экспериментальная функция, только через Anthropic API: не Bedrock, Google Cloud, Foundry. Токены advisor идут в лимиты подписки.
- Советы
	- Задача сложная, Claude путается или ходит по кругу — наверх, на `opus` или `fable`.
	- Рутина (переименования, мелкие правки, вопросы по коду) — `sonnet`: быстрее и меньше тратит лимит.
	- `opusplan` — компромисс: план продумывает Opus, код пишет Sonnet.
	- [Субагентам](subagents.md) для поиска по коду хватит `haiku`: `model: haiku` в их настройках.
	- Claude ошибается в логике — можно сначала поднять [/effort](!effort.md), а не менять модель.
	- Задачи, которые агент не решил, сохранять с описанием. Вышла новая модель — прогнать их заново.
		- ИИздец: часто решаются. Цифр не привёл.
	- Кирилл Мокевнин: для перекрёстной проверки брать встроенный advisor, а не собирать свою связку моделей — хорошие идеи и так быстро попадают в агента.
