- `?` в пустом поле ввода — список клавиш.
- Основные
	- `Esc` — остановить Claude, см. [escape](escape.md).
	- `Esc` `Esc` — в пустом поле [/rewind](!rewind.md), с текстом — очистить поле.
	- `Shift+Tab` — переключить [режим](режимы.md).
	- `Ctrl+C` — прервать. Если ничего не идёт, очищает поле, второе нажатие — выход.
	- `Ctrl+D` дважды — выход.
	- `Alt+P` — сменить модель, см. [/model](!model.md).
	- `Alt+O` — fast mode.
	- `Ctrl+O` — подробный вывод: какие инструменты вызывал Claude.
	- `Ctrl+R` — поиск по истории запросов.
	- `Ctrl+G` — открыть запрос в текстовом редакторе.
	- `Ctrl+S` — отложить набранный запрос. Повторное нажатие в пустом поле вернёт его.
	- `Ctrl+B` — увести запущенную команду в фон. В tmux — дважды. См. [фоновые задачи](фоновые%20задачи.md).
	- `Ctrl+T` — показать или скрыть список задач Claude.
	- `Ctrl+V` — вставить картинку, см. [скриншот](скриншот.md).
	- `Ctrl+L` — перерисовать экран, если он поехал.
- Ввод
	- Новая строка без отправки: `Ctrl+J` или `\` + `Enter` — работают в любом терминале. `Shift+Enter` — в большинстве современных.
	- `/` в начале — команда.
	- `!` в начале — команда терминала, её вывод попадёт в сессию.
	- `@` — упомянуть файл, см. [file mention](file%20mention.md).
	- Vim-режим: [/config](!config.md) → Editor mode.
- Как переназначить
	- `/keybindings` — создаст или откроет `~/.claude/keybindings.json`.
	- Правки подхватываются сразу, без перезапуска.
	- Привязки собраны по контекстам: `Chat` — поле ввода, `Global` — везде, `Confirmation` — окна подтверждения и т. д.
	- Действия записываются как `контекст:действие`: `chat:submit`, `chat:externalEditor`.
	- `null` вместо действия — снять привязку.
	- Пример: `Ctrl+E` открывает внешний редактор, `Ctrl+S` ничего не делает.
		```json
		{
		  "bindings": [
		    {
		      "context": "Chat",
		      "bindings": {
		        "ctrl+e": "chat:externalEditor",
		        "ctrl+s": null
		      }
		    }
		  ]
		}
		```
	- Аккорды: `"ctrl+k ctrl+s"` — нажать по очереди, между нажатиями не больше 3 секунд.
	- Нельзя переназначить: `Ctrl+C`, `Ctrl+D` и ещё несколько, которые терминал присылает как `Enter`, `Tab` или `Esc`.
	- Ошибка в файле не ломает запуск, предупреждение пишется в лог: смотреть через `claude --debug`.
	- Клавиши в файле писать латиницей. С русской раскладкой `Ctrl+буква` может не сработать — зависит от терминала.
- Советы
	- Сначала выучить четыре: `Esc`, `Esc` `Esc`, `Shift+Tab`, `Ctrl+C`. Остальное — по мере надобности.
	- Длинный запрос удобнее писать в редакторе: `Ctrl+G`.
	- Нужно сначала спросить другое — `Ctrl+S` отложит набранное.
	- Вывод команды нужен Claude — `!команда`, а не копировать руками.
	- Не работает `Shift+Enter` — `/terminal-setup`.
