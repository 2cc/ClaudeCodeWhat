- Рабочий пример для [статусной строки](статусная%20строка.md): две строки, темп расхода лимитов, PR и worktree.
- Как выглядит
	- Без цветов:
		```text
		.../ClaudeCodeWhat │ 34.2% │ 5h ━━━━━━━━────┼──────── 41% 2h0m │ 7d ━━━━━━━━━━━┿━━━╾───── 72.5% 3d5h0m
		branch: main │ PR: #12 pending │ worktree: —
		```
	- Нет данных — вместо значения серое `—`. Сегменты не пропадают, и строка не прыгает.
- Первая строка: папка, контекст, лимиты
	- Папка — только последнее имя, жирным.
	- Контекст — процент занятого. Жёлтый от 50%, красный от 80%: пора [сжать](!compact.md) или [очистить](!clear.md).
	- `5h` и `7d` — 5-часовой и недельный лимит, см. [токены и лимиты](токены%20и%20лимиты.md).
		- Полоска, процент израсходованного и серым — сколько осталось до сброса.
- Главная идея — темп, а не процент
	- 40% лимита за первый час и за последний — разные вещи. Важно, успеваешь ли до сброса.
	- Полоска — сколько израсходовано: 20 клеток по 5%.
		- `━` — полная клетка, `╾` — половина, `─` — пусто.
	- Маркер `┼` — сколько окна прошло по времени.
		- Полоска короче маркера — тратишь медленнее, чем идёт время.
		- У маркера та же толщина, что у линии рядом: `┿` внутри заполненного, `┽` на его краю.
	- Цвет — прогноз расхода к концу окна при текущем темпе.
		- Голубой — до 80%, запас.
		- Зелёный — до 105%, в темпе.
		- Жёлтый — до 130%, стоит притормозить.
		- Красный — больше или лимит уже исчерпан.
	- Первые 10% окна прогноз считается так, будто прошло 10%: иначе пара запросов в начале сразу даёт красный.
- Вторая строка: ветка, PR, worktree
	- Ветку скрипт узнаёт сам через `git`: в JSON её нет. Detached HEAD — короткий хеш.
	- PR — номер кликабельной ссылкой (OSC 8) и состояние ревью: `approved` зелёным, `changes_requested` красным.
		- Для GitLab — `!номер` вместо `#номер`.
	- worktree — только в [worktree-сессии](worktrees.md): имя, путь, ветка и серым — откуда пришёл.
- Как устроено
	- Bash только читает JSON и узнаёт ветку. Всё остальное — одна программа `jq`.
	- `refreshInterval: 60` — маркер времени и время до сброса двигаются и без новых ответов Claude.
		```json
		{
		  "statusLine": {
		    "type": "command",
		    "command": "~/.claude/statusline.sh",
		    "refreshInterval": 60
		  }
		}
		```
	- Скрипт `~/.claude/statusline.sh`, сделать исполняемым (`chmod +x`):
		```bash
		#!/bin/bash
		# Статусная строка: текущая директория, контекст, лимиты; ветка, PR и worktree.
		# Все сегменты выводятся всегда; нет данных — «—».
		
		input=$(cat)
		# Текущая ветка git в рабочей директории; detached HEAD — короткий хеш, не репозиторий — пусто.
		dir=$(jq -r '.workspace.current_dir // .cwd // empty' <<<"$input")
		branch=$(git -C "${dir:-.}" branch --show-current 2>/dev/null)
		[ -z "$branch" ] && branch=$(git -C "${dir:-.}" rev-parse --short HEAD 2>/dev/null)
		jq -r --arg home "$HOME" --arg branch "$branch" '
		def c(code): "\u001b[\(code)m" + . + "\u001b[0m";
		def dim: c("2");
		def link(url; text): "\u001b]8;;\(url)\u001b\\\(text)\u001b]8;;\u001b\\";
		def left: if . == null then "—" else ((. - now) | if . < 0 then 0 else . end | . / 60 | ceil) as $m
		  | ($m / 1440 | floor) as $dd | ($m % 1440 / 60 | floor) as $h | ($m % 60) as $mm
		  | (if $dd > 0 then "\($dd)d" else "" end) + (if $dd > 0 or $h > 0 then "\($h)h" else "" end) + "\($mm)m" end;
		def pct: if . == null then "—" else ((. * 10 | round) / 10 | tostring) + "%" end;
		# Полоска из 20 клеток цвета темпа, заполненное отличается толщиной: ━ — заполнено, ╾ — половина клетки, ─ — пусто (шаг 2,5%).
		# Маркер прошедшего времени пересекает линию на границе клеток, ближайшей к прошедшей доле окна;
		# толщина его горизонтали слева/справа повторяет линию по соседству, на краях — ├ ┤.
		def bar($p; $e; $col): ($p / 2.5 | round | if . < 0 then 0 elif . > 40 then 40 else . end) as $n
		  | ($e / 5 | round) as $m
		  | ($n >= $m * 2) as $lh | ($n >= $m * 2 + 1) as $rh
		  | (if $m == 0 then (if $rh then "┝" else "├" end)
		     elif $m == 20 then (if $lh then "┥" else "┤" end)
		     elif $rh then "┿" elif $lh then "┽" else "┼" end | c($col)) as $mark
		  | ([range(20) | ([$n - . * 2, 0] | max | [., 2] | min) as $k
		      | (if . == $m then $mark else "" end)
		        + (["─", "╾", "━"][$k] | c($col))] | join(""))
		    + (if $m == 20 then $mark else "" end);
		# Лимит против времени: полоска — израсходовано, маркер — сколько окна прошло.
		# Цвет по прогнозу расхода к концу окна при текущем темпе:
		# голубой — < 80% (запас), зелёный — до 105% (в темпе), жёлтый — до 130%, красный — больше или лимит исчерпан.
		# Первые 10% окна прогноз считается от 10%, чтобы пара ранних запросов не давала красный.
		def pace($p; $r; $len): if $p == null or $r == null then "—" | dim
		  else ((1 - ($r - now) / $len) * 100 | if . < 0 then 0 elif . > 100 then 100 else . end) as $e
		  | ($p * 100 / ([$e, 10] | max)) as $proj
		  | (if $p >= 100 then "31" elif $proj < 80 then "36" elif $proj <= 105 then "32" elif $proj <= 130 then "33" else "31" end) as $col
		  | bar($p; $e; $col) + " " + ($p | pct | c($col))
		    + (" " + ($r | left) | dim) end;
		def short: if . == null then null else sub("^" + $home; "~") end;
		def line(segs): (segs | map(select(. != null and . != ""))) as $s
		  | if ($s | length) == 0 then empty else $s | join(" │ " | dim) end;
		
		. as $d |
		
		# 1. текущая директория, контекст, лимиты
		line(
		  [ ($d.workspace.current_dir // $d.cwd | if . == null then "—" elif . == "/" then "/" else ".../" + (split("/") | last | c("1")) end),
		    ($d.context_window.used_percentage
		       | . as $p | pct | if $p == null then dim elif $p >= 80 then c("31") elif $p >= 50 then c("33") else . end),
		    "5h " + pace($d.rate_limits.five_hour.used_percentage; $d.rate_limits.five_hour.resets_at; 18000),
		    "7d " + pace($d.rate_limits.seven_day.used_percentage; $d.rate_limits.seven_day.resets_at; 604800) ]),
		
		# 2. ветка, PR и worktree-сессия
		line(
		  [ "branch: " + (if $branch == "" then "—" | dim else $branch | c("1") end),
		    "PR: " + (if $d.pr then
		       link($d.pr.url; (if $d.pr.kind == "mr" then "!" else "#" end) + ($d.pr.number | tostring))
		       + (if $d.pr.review_state then " " + ($d.pr.review_state
		           | if . == "approved" then c("32") elif . == "changes_requested" then c("31") else dim end) else "" end)
		     else "—" | dim end),
		    "worktree: " + (if $d.worktree then
		       "\($d.worktree.name) \(($d.worktree.path | short))"
		       + (if $d.worktree.branch then " (" + $d.worktree.branch + ")" else "" end)
		       + (" ← " + ($d.worktree.original_cwd | short) + (if $d.worktree.original_branch then " @" + $d.worktree.original_branch else "" end) | dim)
		     else "—" | dim end) ])
		' <<<"$input"
		```
