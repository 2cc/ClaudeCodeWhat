- Долгая команда запускается в фоне: Claude получает её ID и продолжает работать, не дожидаясь конца.
- Типичное: dev-сервер, сборка, тесты, `docker`, `terraform`.
- Как увести в фон
	- Попросить словами: «запусти сервер в фоне».
	- `Ctrl+B` — увести уже запущенную команду. В tmux — дважды. См. [горячие клавиши](горячие%20клавиши.md).
	- Работает и для своих команд через `!` в начале строки.
	- Команда упёрлась в таймаут — Claude Code сам уводит её в фон, а не убивает. Кроме `sleep`.
- Что с выводом
	- Вывод пишется в файл, Claude читает его, когда нужно: «что там в логах сервера?».
	- Больше 5 ГБ вывода — команду убивают.
- Управление
	- `/tasks` (он же `/bashes`) — список фоновых команд и [субагентов](subagents.md), там же остановить.
	- `Ctrl+X Ctrl+K` дважды — остановить все фоновые субагенты.
	- Не путать с `Ctrl+T` — это список дел Claude, а не фоновые задачи.
- Ограничения
	- Лимит времени — 30 минут с момента ухода в фон. Если Claude при запуске попросил больше — до 2 часов.
	- При выходе из Claude Code все фоновые задачи останавливаются.
	- Фоновая команда, которую запустил субагент на переднем плане, заканчивается вместе с ним.
	- Выключить фон совсем: `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1`.
- Советы
	- Dev-сервер запускать в фоне: Claude сможет сам смотреть его логи после правок.
	- Долгие тесты — в фоне, пока Claude делает другое.
	- Ненужные останавливать через `/tasks`.
